# Experimental Windows x64 build

[Download the 2026-10-18 asset-free build](https://github.com/wigwoo1/Crazy-Taxi-Catch-A-Ride-PC-Port/raw/refs/heads/main/downloads/Crazy-Taxi-Native-Windows-x64-2026-10-18-Asset-Free.zip).

**This is not a standalone playable download.** It requires original resources extracted locally from your own USA game ROM. A clean one-click extraction installer is not yet finished. Users with an existing development extraction can copy their `outputs/crazy-taxi-native/assets` folder into the extracted package at that same relative location and run `Launch.cmd`. The launcher keeps an error log and explains missing resources.

The exact executable passed the strict 379-module build, 65 original bitmap comparisons, 80 digit-pair comparisons, three 4K rank comparisons, and native startup/driving/pause Retry/resume checks. Executable SHA256: `e25935b1dde9cafbac84db51d6f617dfcea2f984104305d3f9867c0a099fbac9`.

Full-game fidelity, sustained 60 fps, physical Xbox testing and other-PC compatibility remain unverified. No ROM, extracted assets, music, saves, or credentials are included. Source publication is being completed separately.
